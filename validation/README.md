# Résultats de qualification

Les rapports 0.1.3 correspondent à la recette complète sur les distributions Mautic 4.4.13, 5.2.11 et 6.0.9 : 529 assertions au total. Le contrôle navigateur a été exécuté uniquement sur Mautic 6.0.9.

La version 0.1.4 retire le préfixe du titre affiché de l’action. Les traductions sont vérifiées avec les chargeurs natifs des trois distributions ; la recette complète 0.1.3 n’est pas présentée comme une nouvelle exécution en 0.1.4.

Les rapports emploient des fixtures synthétiques et un transport de capture. Aucun destinataire métier, secret d’installation, base de données ou journal de production n’est inclus. Voir [la recette et ses limites](../docs/validation.md).
